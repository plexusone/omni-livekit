# v0.5.0

**Release Date:** 2026-08-08

Room recording via LiveKit Egress, plus fixes for a build breakage introduced by the omniavatar-core v0.4.0 API restructuring.

## Highlights

- Room recording via LiveKit Egress with local file and S3 output
- Fixed build breakage from the omniavatar-core v0.4.0 API restructuring

## Added

- `room.RecordingClient` for room recording via LiveKit Egress ([`eac1bfe`](https://github.com/plexusone/omni-livekit/commit/eac1bfe))
- `room.RecordingConfig` with layout, format, and local/S3 output options ([`eac1bfe`](https://github.com/plexusone/omni-livekit/commit/eac1bfe))
- `RecordingClient.StartRecording()` to start a room composite egress recording ([`eac1bfe`](https://github.com/plexusone/omni-livekit/commit/eac1bfe))
- `RecordingClient.StopRecording()` to end an active recording ([`eac1bfe`](https://github.com/plexusone/omni-livekit/commit/eac1bfe))
- `RecordingClient.ListRecordings()` to query active egress sessions for a room ([`eac1bfe`](https://github.com/plexusone/omni-livekit/commit/eac1bfe))
- MP4 and OGG output formats via `room.RecordingFormat` ([`eac1bfe`](https://github.com/plexusone/omni-livekit/commit/eac1bfe))
- Grid, speaker, and single-speaker layouts via `room.RecordingLayout` ([`eac1bfe`](https://github.com/plexusone/omni-livekit/commit/eac1bfe))

## Fixed

- `avatar.LiveKitSession` build failure: `avcore.Session`/`avcore.SessionCallbacks` now resolve from `omniavatar-core/live`, where those types actually live as of omniavatar-core v0.4.0 ([`d40fbfd`](https://github.com/plexusone/omni-livekit/commit/d40fbfd))
- `agent.startAvatarLocked` build failure: same `avcore` import fix, plus renamed the removed `omniavatar.GetAvatarProvider` call to `omniavatar.GetLiveProvider` ([`531f5fd`](https://github.com/plexusone/omni-livekit/commit/531f5fd))
